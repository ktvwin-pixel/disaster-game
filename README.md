# 재난소통 영웅

재난 현장에서 피해자·시민과 다섯 번씩 대화하며 상황에 맞는 소통 답변을 직접 입력해 훈련하는 웹 게임입니다.

- 7개 재난 관문: 침수 · 화재 · 지진 · 폭발 · 폭염 · 건물붕괴 · 감염병확산
- 문제은행 360문항: 구조대상자 20개 대상 × 5단계 × 3문항 = 300문항 + 취재 기자 질문 20개 상황 × 3문항 = 60문항
- 한 관문 = 구조대상자 대화 5번 + 기자 질문 3번, 핵심 포인트는 그림으로 보여 복사·붙여넣기 불가
- 복장 5종(민방위 대원 · 소방대원 · 경찰공무원 · 공무원 · 일반인), 남녀 선택
- 직접 입력 또는 음성 받아쓰기, 휴대폰·태블릿·PC 화면 자동 조정
- 자체 제작 배경음악과 판정 효과음(켜기/끄기 가능)
- 인증번호 기반 랭킹: 운영자가 발급한 인증번호로 참여, 관문을 마칠 때마다 내 순위 표시
  - 랭킹만 바로 보기: https://ktvwin-pixel.github.io/disaster-game/#ranking
  - 인증번호가 없으면 랭킹 화면에서 바로 신청 → 자동 발급(또는 운영자 승인 후 이메일 발송)
  - 랭킹 서버: `server/Code.gs` (구글 시트 + Apps Script)
